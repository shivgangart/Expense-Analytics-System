Expense Analytics System

Project Overview

The Expense Analytics System is a Python-based application developed to manage, track, and analyse daily expenses. It uses SQLite for database management and Python data structures for efficient expense processing and analysis.

Features

- Add new expenses
- View all recorded expenses
- Update and delete expenses
- Search expenses
- Sort expenses
- Category-wise expense analysis
- Monthly expense summaries
- Identify top spending categories

Technologies Used

- Programming Language: Python
- Database: SQLite
- Data Structures: Lists, Dictionaries and Heap
- Modules: sqlite3, datetime, collections and heapq

Installation and Execution

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the main Python file using Python IDLE or a terminal.

python main.py

Project Purpose

This project demonstrates the practical application of Python programming, database management, and data structures in solving everyday expense-management problems.
